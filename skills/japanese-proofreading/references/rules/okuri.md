# 送り仮名（OKURI）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

基準は「送り仮名の付け方」（昭和48年内閣告示）。漢字で書く場合の送り仮名に適用する。開くかどうかは `hiraku.md` で別に判定する。

### OKURI-01 よくある誤り【誤り】

| 誤 | 正 |
|---|---|
| 必らず | 必ず |
| 少くない | 少なくない |
| 短かい | 短い |
| 新らしい | 新しい |
| 美くしい | 美しい |
| 著るしい | 著しい |
| 確める | 確かめる |
| 承わる | 承る |
| 志ざす | 志す |
| 携さわる | 携わる |
| 危い | 危ない |
| 明か（あきらか）| 明らか |
| 少い | 少ない |
| 確に | 確かに |
| 恐しい | 恐ろしい |
| 珍らしい | 珍しい |
| 潔よい | 潔い |

「浮ぶ」「押える」「終る」などは誤りではなく許容（OKURI-04）。上の表は許容にも含まれない誤りだけを挙げている。

### OKURI-02 活用語の原則（通則1）【誤り】

活用語尾を送る：書く、生きる、考える、助ける、荒い、潔い。

例外として、次のように送る。

- 語幹が「し」で終わる形容詞は「し」から送る：著しい、惜しい、悔しい、恋しい、珍しい
- 「か」「やか」「らか」を含む形容動詞はそこから送る：暖かだ、静かだ、穏やかだ、健やかだ、明らかだ、滑らかだ、柔らかだ
- 個別の語：明らむ、味わう、哀れむ、慈しむ、教わる、脅かす、関わる、食らう、異なる、逆らう、捕まる、群がる、和らぐ、揺する、明るい、危ない、危うい、大きい、少ない、小さい、冷たい、平たい、新ただ、同じだ、盛んだ、平らだ、懇ろだ、惨めだ、哀れだ、幸いだ、幸せだ、巧みだ

### OKURI-03 派生・対応する語に合わせる（通則2）【誤り】

本則・許容（OKURI-04）のどちらにも当たらない送り方を誤りとする。

他の語を含む活用語は、含まれる語の送り方に合わせる。

- 動かす（動く）、照らす（照る）、浮かぶ（浮く）、生まれる（生む）、押さえる（押す）、捕らえる（捕る）、積もる（積む）、聞こえる（聞く）、頼もしい（頼む）、起こる（起きる）、落とす（落ちる）、終わる（終える）、変わる（変える）、当たる（当てる）、確かめる（確かだ）、重んずる（重い）、細かい（細かだ）

### OKURI-04 許容される送り方【任意】

次は本則・許容のどちらも誤りではない。文書内で統一されているかだけを見る。迷ったら本則を採る。

| 本則 | 許容 |
|---|---|
| 行う | 行なう |
| 表す | 表わす |
| 著す | 著わす |
| 現れる | 現われる |
| 断る | 断わる |
| 賜る | 賜わる |

通則2の許容（読み間違えるおそれがなければ、含まれる語の送り仮名を省ける）：

| 本則 | 許容 |
|---|---|
| 浮かぶ | 浮ぶ |
| 生まれる | 生れる |
| 押さえる | 押える |
| 捕らえる | 捕える |
| 起こる | 起る |
| 落とす | 落す |
| 暮らす | 暮す |
| 当たる | 当る |
| 終わる | 終る |
| 変わる | 変る |
| 積もる | 積る |
| 聞こえる | 聞える |

### OKURI-05 名詞（通則3・4）【誤り】

- 活用のない名詞は送らない：月、鳥、花、山
- 例外として最後の音節を送る：辺り、哀れ、勢い、幾ら、後ろ、傍ら、幸い、幸せ、互い、便り、半ば、情け、斜め、独り、誉れ、自ら、災い
- 数を数える「つ」は送る：一つ、二つ、幾つ
- 活用語から転じた名詞は元の語に従う：動き、恐れ、曇り、調べ、届け、願い、晴れ、当たり、代わり、向かい、答え、問い、祭り、群れ、憩い、初め、近く
- 「さ」「み」「げ」が付いた名詞：暑さ、大きさ、正しさ、確かさ、明るみ、重み、憎しみ、惜しげ
- 送らない慣用の名詞：謡、虞、趣、氷、印、頂、帯、畳、卸、煙、恋、志、次、隣、富、恥、話、光、舞、折、係、組、肥、並、巻、割

### OKURI-06 副詞・連体詞・接続詞（通則5）【誤り】

- 最後の音節を送る：必ず、更に、少し、既に、再び、全く、最も、来る（きたる）、去る、及び、且つ、但し
- 例外：明くる、大いに、直ちに、並びに、若しくは
- 他の語を含むものは含まれる語に合わせる：併せて、至って、恐らく、従って、絶えず、例えば、努めて、辛うじて、少なくとも、互いに、必ずしも

（これらの多くは `hiraku.md` のルールで開く対象にもなる。漢字で書く場合にこの送り仮名を使う。）

### OKURI-07 複合語【任意】

- 動詞は各要素の送り仮名どおりに送る：申し込む、取り扱う、打ち合わせる、書き換える、受け付ける、引き継ぐ
- 名詞形は送り仮名を省くことがある（「申し込み／申込み」「取り扱い／取扱い」「打ち合わせ／打合せ」）。文書内で統一されているかだけを見る。
- 慣用として送り仮名を付けない複合名詞は送らない：受付（窓口の意）、申込書、取扱説明書、書留、切手、日付、手当、見積書、売上高、引継書
- 動詞の名詞形と、慣用で固定した名詞を区別する。「申し込みを受け付ける」「受付で手続きする」のように、動作を表す場合は送り、窓口・書類名などの固定した名詞では送らない。
