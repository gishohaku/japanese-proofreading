# 構造・参照・リンク（KOZO）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

文や語ではなく、文書の構造（見出し、図表、脚注、リンク）に関するもの。`scripts/consistency.py` が、見出しの階層の飛び、代替テキストのない画像、行き先のわからないリンクテキストを集計する。リンク先が実際に開けるかどうかは確かめない。

### KOZO-01 図・表・リストの番号と参照【要確認】

- 本文が参照している図・表・リストが、原稿の中にあるか（「図3-2 を参照」とあるが図3-2 がない）。
- 番号が重複していないか、飛んでいないか。
- 本文から一度も参照されない図・表がないか。
- 図・表・リストにキャプションがあるか。

Re:VIEW では `@<img>{id}`、`@<list>{id}`、`@<table>{id}` の id が、`//image[id]`、`//list[id]`、`//table[id]` と対応しているかを見る。Markdown で番号を手で書いている場合は、番号の並びを見る。

図や表を別ファイルに置いていて原稿から確かめられない場合は、指摘しない。

### KOZO-02 見出しの階層【推奨】

見出しの階層を飛ばさない（`##` の直後に `####`）。目次や読み上げで構造が崩れる。Re:VIEW では `=` の数で同じように見る。同じ階層の見出しの形を揃えることは TOITSU-09 で扱う。

### KOZO-03 リンクテキスト【推奨】

リンクテキストだけを読んで、行き先がわかるようにする。

```
△ 詳細は[こちら](https://example.com/docs/install)を参照してください。
○ 詳細は[インストール手順](https://example.com/docs/install)を参照してください。
```

- 「こちら」「ここ」「このページ」「リンク」だけのリンクテキストを指摘する。
- URL をそのまま本文に書くのは、紙の書籍では可。Web では、行き先がわかる語にする。
- PDF などページ以外へのリンクは、形式がわかるようにする（「申請書（PDF）」）【任意】。
- 同じリンクテキストで行き先が違うもの、同じ行き先でリンクテキストが違うものは、揃える【任意】。

### KOZO-04 画像の代替テキストとキャプション【推奨】

- Web 記事・ドキュメントでは、画像に代替テキストを付ける（`![設定画面のスクリーンショット](...)`）。「画像」「スクリーンショット」「image1」のように内容がわからない代替テキストも指摘する。
- 図の内容を本文でも説明する。「図のとおり」だけで済ませると、図を見られない読み手に伝わらない。
- 色や位置だけで指示しない（「赤いボタンを押す」「右側の欄」→ ボタンや欄の名前を書く）【任意】。
- 紙の書籍向けの Re:VIEW の原稿では、代替テキストは求めず、キャプションの有無だけを見る。

### KOZO-05 脚注【要確認】

- 脚注の参照（`[^1]`、`@<fn>{id}`）と本体（`[^1]:`、`//footnote[id]`）が対応しているか。参照のない脚注、本体のない参照を指摘する。
- 脚注の本体は、参照している段落の近くに置く（Re:VIEW では参照より前に置くとエラーになる場合がある）【任意】。
- 脚注の文末・文体は本文に合わせる（TOITSU-03）。

### KOZO-06 UI 要素・キー・コマンドの書き方【任意】

画面上の要素やキーの書き方を、文書内で揃える。どの記号を使うかは方針次第。

| 対象 | 揃える点 | 例 |
|---|---|---|
| ボタン・メニュー・タブ | 囲む記号 | ［保存］をクリックする／「保存」をクリックする |
| 画面に表示されるメッセージ | 囲む記号 | 「保存しました」と表示される |
| メニューの階層 | 区切りの記号 | ［設定］>［権限］／［設定］→［権限］ |
| キー | 表記と連結の記号 | Ctrl+C／Ctrl + C、Enter／エンター／⏎ |
| 操作の動詞 | 語 | クリックする／押す／選択する／タップする |
| コマンド・ファイル名 | インラインコードにするか | `npm install` を実行する |

- 画面の文言は、表示どおりに引用する。本文の表記方針（長音、送り仮名、開く漢字）に合わせて書き換えない。この引用の中は校正の対象外（`../checklist.md` の「対象外」）。
- 同じ画面要素を別の名前で呼んでいる場合（［保存］と［セーブ］）は、どちらが画面の表示かを「要確認」で尋ねる。
- 手順の書き方（1手順1操作、結果の確認）は、査読の TW-L04 で扱う。
