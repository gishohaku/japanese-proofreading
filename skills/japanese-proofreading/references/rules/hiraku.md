# 開く漢字（HIRAKU）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

漢字を「開く」とは、ひらがなで書くこと。基本的な考え方は次のとおり。

- **実質的な意味が薄れた語（形式名詞・補助動詞など）は開く。** 本来の意味で使う場合は漢字のまま。
- **常用漢字表にない漢字・読み（表外字・表外音訓）は開く**か、言い換える。
- 開きすぎると読みにくくなる（「ほぞんしたふぁいるを」）。漢字とかなの割合はおおむね漢字3割前後を目安とし、文書内で統一する。

重要度は、表外字・当て字を開くものは【推奨】、それ以外は【任意】（文書の表記方針に従う）とする。

### HIRAKU-01 形式名詞【任意】

| 閉じる | 開く | 漢字のままにする例（実質名詞）|
|---|---|---|
| 事 | こと（確認する事→確認すること）| 事を荒立てる、事の発端 |
| 物 | もの（使える物→使えるもの）| 物を片付ける |
| 時 | とき（失敗した時→失敗したとき）| 時を刻む、実行時 |
| 所 | ところ（現在の所→現在のところ）| 所在地、置き所 |
| 為 | ため | — |
| 訳 | わけ（使えない訳ではない）| 翻訳、訳文 |
| 筈 | はず | — |
| 内 | うち（数回の内→数回のうち）| 内側、社内 |
| 方 | ほう（こちらの方が速い→ほう）| 使い方、方向 |
| 通り | とおり（次の通り→次のとおり）| 大通り |
| 程 | ほど | 程度 |
| 様 | よう（次の様に→次のように）| 様子、仕様 |
| 毎 | ごと（1時間毎→1時間ごと）| 毎日、毎回 |
| 等 | など（AやB等→AやBなど）| 等号、同等 |
| 位 | くらい・ぐらい | 位置、上位 |
| 迄 | まで | — |
| 頃 | ころ・ごろ | — |

### HIRAKU-02 補助動詞・補助形容詞【任意】

動詞・形容詞が他の動詞に付いて補助的に使われる場合は開く。

| 補助的用法（開く）| 本来の用法（漢字）|
|---|---|
| 増えていく | 会場へ行く |
| 試してみる | 画面を見る |
| 保存しておく | 机に置く |
| 消えてしまう | — |
| 動いている | — |
| 書いてある | — |
| 教えてもらう | 賞をもらう（「貰」は表外字のため、本来の用法でも開く）|
| 確認してください | 資料を下さい |
| 修正してほしい | 時間が欲しい |
| 変更してよい | 品質が良い |
| 読みにくい | — |
| 使いやすい | — |
| 問題ない・できない | — |

### HIRAKU-03 よく使う動詞【任意】

| 閉じる | 開く | 備考 |
|---|---|---|
| 出来る | できる | 可能の意味。「出来が良い」「出来上がる」は漢字 |
| 言う | いう | 「〜という」「いわゆる」。発言の意味では漢字 |
| 有る・在る | ある | — |
| 居る | いる | — |
| 成る | なる | 「〜になる」 |
| 為る | する | — |
| 頂く | いただく | 補助動詞（〜していただく）は開く |
| 致す | いたす | 補助的用法は開く |
| 分かる | わかる | 【任意】文書内で統一 |
| 掛ける | かける | 「電話をかける」「時間をかける」など。「壁に掛ける」は漢字【任意】|
| 〜て来る | 〜てくる | 補助動詞（持ってくる）。HIRAKU-02 と同じ |

ICS MEDIA の辞書には「無駄→ムダ」「お勧め→オススメ」のようにカタカナにするルールもある。これはメディア固有の方針なので、本ルール集では採らない。採用する場合は文書の表記方針として明示する。

### HIRAKU-05 接続詞【任意】

一般書・技術書では開くのが一般的。公用文の方針を採る文書では「及び」「並びに」「又は」「若しくは」だけ漢字にする。

| 閉じる | 開く |
|---|---|
| 及び | および |
| 並びに | ならびに |
| 又は | または |
| 若しくは | もしくは |
| 又 | また |
| 且つ | かつ |
| 但し | ただし |
| 尚 | なお |
| 従って | したがって（「指示に従って」は漢字）|
| 即ち | すなわち |
| 或いは | あるいは |
| 故に | ゆえに |
| 然し・然し乍ら | しかし・しかしながら |
| 更に | さらに |
| 因みに | ちなみに |

### HIRAKU-08 表外字・表外訓・難読語【推奨】

常用漢字表にない字は、開く・言い換える・ルビを振るのいずれかにする。

| 表外字 | 対応例 |
|---|---|
| 綺麗 | きれい |
| 曖昧 | あいまい【任意】（2010年に常用漢字に追加されたが、開く方針も多い）|
| 稀 | まれ |
| 呟く | つぶやく |
| 纏める | まとめる |
| 揃える | そろえる |
| 拘る | こだわる |
| 嵌る | はまる |
| 捗る | はかどる |
| 煩い | うるさい（「煩わしい」は可）|
| 齟齬 | 食い違い（言い換え）|
| 杜撰 | ずさん |
| 脆弱性 | そのまま（専門用語は漢字＋必要ならルビ）|

交ぜ書き（「改ざん」「漏えい」など）は報道・公用文で定着しているので、専門用語として文書内で統一されていれば可【任意】。
