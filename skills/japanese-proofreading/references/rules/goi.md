# 語彙・表記（GOI）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

### GOI-01 表記の基準（外来語・英字）【任意】

語をどう書くかの基準。文書内で揺れているかどうかの判定は TOITSU-01 で行う。

- 外来語の長音：原語の語尾が -er、-or、-ar の語は長音を付ける（サーバー、ユーザー、アダプター、コンパイラー、エディター、ブラウザー、パラメーター）。内閣告示「外来語の表記」に準拠した、現在主流の表記。JIS 規格の慣習で長音を省く文書もあるので、方針が「省く」なら統一されているかだけを見る。
- -y で終わる語（エントリ／エントリー、カテゴリ／カテゴリー、メモリ／メモリー）は文書によって分かれる。
- 外来語の表記：インターフェース／インタフェース／インターフェイス、ウェブ／ウエブ、バイオリン／ヴァイオリンなどは、どれも誤りではない。
- 英字の固有名詞は公式表記に合わせる（GOI-11。これは【誤り】）。
- 全角・半角は MOJI-02、数字は MOJI-03 で扱う。

### GOI-02 同音異義語・異字同訓【誤り】

文脈から誤りと判断できる場合に指摘する。

| 語 | 使い分け |
|---|---|
| 計る／測る／量る／図る | 時間・数（計る）、長さ・面積・程度（測る）、重さ・容積（量る）、企て・意図（図る）|
| 保証／保障／補償 | 間違いないと請け合う／地位・状態を守る／損失を補う |
| 対象／対称／対照 | 目標とするもの／つり合い／比べ合わせる |

| 初め／始め | 時間的に早い段階（初めて、年の初め）／物事を始めること（仕事始め、始めと終わり）|
| 収める／納める／治める／修める | 成果・中に入れる／金品・納品／統治・鎮める／学問・身を正す |

| 移動／異動／異同 | 位置が動く／人事上の変更／違い |
| 回答／解答 | 質問・照会への返事／問題の答え |
| 規定／規程 | 個々の条文の定め／一連の規則の総体 |
| 制作／製作 | 芸術作品・コンテンツ／機械・道具・工業製品 |
| 最小／最少 | 大きさ／数量 |
| 意外／以外 | 思いがけない／それを除いたもの |
| 関心／感心 | 興味／感服 |
| 適用／適応 | 当てはめる／環境に合う |
| 作成／作製 | 書類・計画／物品・図面 |
| 機能／帰納 | 働き／個別から一般を導く推論 |
| 押さえる／抑える | 手で動かないようにする・要点をつかむ／勢いを食い止める（コストを抑える）|

### GOI-03 ら抜き・さ入れ・れ足す言葉【誤り】

| 種類 | 誤 | 正 |
|---|---|---|
| ら抜き | 見れる、来れる、食べれる、起きれる | 見られる、来られる、食べられる、起きられる |
| さ入れ | 読まさせていただく、休まさせる | 読ませていただく、休ませる |
| れ足す | 書けれる、行けれる | 書ける、行ける |

判定方法：一段動詞・カ変動詞の可能形は「られる」。五段動詞の使役は「〜せる」（「読む」→「読ませる」）。

### GOI-06 前後を指す語【任意】

縦書き・改ページを考慮する書籍では「上記・下記・上述・以下」を「前述・次の・前項」などに置き換える。Web 記事など横書きでスクロールする媒体では「上記・下記」も可。文書の媒体に合わせる。

### GOI-07 過剰な敬語・婉曲表現【推奨】

- 「させていただく」は、相手の許可を得て行う場合に限る。単なる行為の報告なら「します」でよい（「説明させていただきます」→「説明します」）。
- 二重敬語（「おっしゃられる」「お伺いさせていただく」）は【誤り】。
- 「〜と思われます」「〜かもしれません」「〜と考えられます」が続く文章は、根拠があるなら言い切る形を提案する（textlint：`ja-no-weak-phrase`）。
- 役職に敬称を重ねない：「部長様」「社長殿」→「部長」「社長」。「各位殿」→「各位」。

### GOI-08 「〜的」「〜化」「〜性」の多用【任意】

一文に「〜的」「〜化」が複数ある場合や、具体的な語に置き換えられる場合に指摘する（「効率的な最適化を実現的に行う」→「効率よく最適化する」）。

### GOI-09 冗長な表現【推奨】

| 冗長 | 簡潔 |
|---|---|
| 〜することができる | 〜できる |
| 〜を行う（設定を行う）| 〜する（設定する）|
| 〜を実施する（テストを実施する）| 〜する【任意】|
| 〜していきます | 〜します【任意：継続・進行の意味があれば可】|
| 〜があるものである | 〜がある |
| 〜ということになる | 〜となる、〜だ |
| 〜であるということ | 〜であること |
| 〜という形で | 〜として |
| 〜というふうに | 〜のように |
| 〜必要性がある | 〜必要がある |
| 〜することが可能だ | 〜できる |
| 〜のほうが（比較の対象がない）| 削る |
| 〜させていただきます | 〜いたします、〜します |

「〜することができる」は、主体の能力・制度上の可否を強調したい場合（「管理者だけが削除することができる」）は残してよい。

### GOI-11 固有名詞・技術用語の表記【誤り】

| Webpack | webpack |

### GOI-12 誤字・脱字・衍字・誤変換【誤り】

入力や変換の単純なミス。意味の使い分けを誤っている場合は GOI-02、慣用句の誤りは GOI-10 で扱う。

| 種類 | 誤 | 正 |
|---|---|---|
| 誤変換 | 以上終了する、再起同する、機能を追加下 | 異常終了する、再起動する、機能を追加した |
| 脱字 | 設定を変更ます、ファイルを保存すると通知表示されます | 設定を変更します、通知が表示されます |
| 衍字（余分な字）| 設定をを変更します、確認しますます | 設定を変更します、確認します |
| 入力ミス | 対応でkiる、実行すうｒ | 対応できる、実行する |
| 英単語のつづり | recieve、enviroment、seperate | receive、environment、separate |

- 助詞の脱落（「ファイル保存する」「項目名変更します」）は、話し言葉の省略として書かれている場合もある。本文では助詞を補う形を【推奨】で示す。見出しや箇条書きの体言止めに近い形（「ファイル保存」）は指摘しない。
- 英単語のつづりは、本文中で語として使っている箇所だけを見る。コード、識別子、コマンドは対象外（`../checklist.md` の「対象外」）。
- 誤りと断定できない場合（見慣れない固有名詞、造語、意図的な表記かもしれない語）は「要確認」とする。
- textlint が検出するのは、同じ語の連続（JOSHI-10）とローマ字の混入（`ja-unnatural-alphabet`）だけ。誤変換と脱字は、文を読んで意味が通るかで判断する。

### GOI-13 範囲・境界の表現【推奨】

基準の値を含むかどうかが、語によって決まっている。仕様・条件・手順を述べる文で、含む・含まないが読み手に伝わるかを見る。

| 基準の値を含む | 基準の値を含まない |
|---|---|
| 10以上、10以下 | 10を超える、10未満 |
| 4月1日以前、4月1日以降（以後）| 4月1日より前、4月1日より後 |
| 〜から〜まで | — |

```
△ 10件以上はエラーになります。      （実際は11件からエラー）
○ 10件を超えるとエラーになります。
```

- 「以内」「まで」は、基準の値を含む（「3日以内」は3日目を含む）。
- 「バージョン 8.3 以降」は 8.3 を含む。「8.3 より新しい」は含まない。
- 「〜ぶり」「〜年目」「〜周年」は起算の仕方で1つずれやすい。日付や年が原稿にあれば計算して確かめる。
- 「早めに」「しばらく」「いくつか」など幅のある語は、読み手が行動を決める文では具体的な数や期限にする（査読の TW-C03、TW-L01 と重なる。校正では、手順・条件の文だけを見る）。
- 本文の条件とコード・表の条件が食い違っている場合（本文は「以上」、コードは `>`）は、SEIGO-01 の「要確認」として出す。

### GOI-14 本来の意味と異なる意味で使われている語【推奨】

本来の意味と、広く使われている意味が分かれている語。どちらの意味で読まれるかが読み手によって変わるので、誤りと断定せず、誤解されにくい語への言い換えを示す。本来の意味で使っている場合も、読み手に伝わりにくければ同じ扱いにする。

| 語 | 本来の意味 | 広まっている意味 | 言い換えの例 |
|---|---|---|---|
| 役不足 | 力量に対して役目が軽い | 力量が足りない（力不足）| 力不足、荷が重い |
| 敷居が高い | 不義理があって行きにくい | 高級・難しそうで近寄りにくい | ハードルが高い、始めにくい |
| 煮詰まる | 議論が出尽くして結論が出る段階になる | 行き詰まる | 行き詰まる／結論が見えてくる |
| 確信犯 | 信念に基づいて正しいと信じて行う行為 | 悪いと知りながら行う行為 | 故意に、意図的に |
| 姑息 | 一時しのぎ | ひきょう | その場しのぎの／ひきょうな |
| 割愛する | 惜しみながら省く | 不要なので省く | 省略する |
| なし崩し | 少しずつ片付けていく | うやむやにする | 少しずつ／うやむやに |
| さわり | 話の要点、聞かせどころ | 話の最初の部分 | 要点／冒頭 |
| おもむろに | ゆっくりと | 突然 | ゆっくりと／突然 |
| 潮時 | ちょうどよい時期 | やめどき | よい時期／やめどき |
| ひもとく | 書物を開いて読む | 謎や真相を明らかにする | 読み解く、明らかにする |
| 課金する | 提供者が料金を課す | 利用者が料金を支払う | 料金を支払う、購入する |

技術書では「課金」の向き（誰が誰に課すのか）が料金体系の説明で誤読につながりやすい。

### GOI-15 読み手への配慮【任意】

読み手を突き放したり、特定の人を前提にしたりする表現。文書の方針として決めるものなので、気づいた箇所を1件にまとめて示す。網羅的に探さない。

- **主観的な難易度**：「簡単に」「単に」「〜するだけ」「誰でも」「当然」「言うまでもなく」。つまずいた読み手は自分が劣っていると受け取る。手順や所要時間など、具体的な情報に置き換える。

```
△ 設定は簡単で、ファイルを1行書き換えるだけです。
○ 設定は、ファイルの1行を書き換えます。
```

- **性別・属性を前提にした語**：「彼（不特定のユーザーを指して）」「〜マン（営業マン、キーマン）」「女医」「女性でも使える」。「ユーザー」「担当者」「医師」などにする。
- **技術用語**：master／slave、whitelist／blacklist は、言い換え（primary／replica、allowlist／blocklist など）が進んでいる。対象の製品・プロジェクトが現在使っている公式の用語に合わせる（GOI-11）。公式の用語がそのままなら変えない。
- 引用、歴史的な経緯の説明、固有名詞は対象外。過剰な言い換えで意味が伝わらなくなる場合は指摘しない。
