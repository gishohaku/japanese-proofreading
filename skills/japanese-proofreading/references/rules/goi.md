# 語彙・表記（GOI）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

### GOI-01 表記の基準（外来語・英字）【任意】

語をどう書くかの基準。文書内で揺れているかどうかの判定は TOITSU-01 で行う。

- 外来語の長音：原語の語尾が -er、-or、-ar の語は長音を付ける（サーバー、ユーザー、アダプター、コンパイラー、エディター、ブラウザー、パラメーター）。内閣告示「外来語の表記」に準拠した、現在主流の表記。JIS 規格の慣習で長音を省く文書もあるので、方針が「省く」なら統一されているかだけを見る。
- -y で終わる語（エントリ／エントリー、カテゴリ／カテゴリー、メモリ／メモリー）は文書によって分かれる。
- 外来語の表記：インターフェース／インタフェース／インターフェイス、ウェブ／ウエブ、バイオリン／ヴァイオリンなどは、どれも誤りではない。
- 英字の固有名詞は公式表記に合わせる（GOI-11。これは【誤り】）。
- 全角・半角は MOJI-02、数字は MOJI-03 で扱う。

### GOI-02 同音異義語・異字同訓【誤り】

文脈から誤りと判断できる場合に指摘する。

| 語 | 使い分け |
|---|---|
| 計る／測る／量る／図る | 時間・数（計る）、長さ・面積・程度（測る）、重さ・容積（量る）、企て・意図（図る）|
| 保証／保障／補償 | 間違いないと請け合う／地位・状態を守る／損失を補う |
| 対象／対称／対照 | 目標とするもの／つり合い／比べ合わせる |
| 追求／追及／追究 | 目的を追い求める／責任を問い詰める／真理を突き詰める |
| 初め／始め | 時間的に早い段階（初めて、年の初め）／物事を始めること（仕事始め、始めと終わり）|
| 収める／納める／治める／修める | 成果・中に入れる／金品・納品／統治・鎮める／学問・身を正す |
| 表す／現す／著す | 表現する／姿を見せる／書物を書く |
| 移動／異動／異同 | 位置が動く／人事上の変更／違い |
| 回答／解答 | 質問・照会への返事／問題の答え |
| 規定／規程 | 個々の条文の定め／一連の規則の総体 |
| 制作／製作 | 芸術作品・コンテンツ／機械・道具・工業製品 |
| 最小／最少 | 大きさ／数量 |
| 意外／以外 | 思いがけない／それを除いたもの |
| 関心／感心 | 興味／感服 |
| 適用／適応 | 当てはめる／環境に合う |
| 作成／作製 | 書類・計画／物品・図面 |
| 機能／帰納 | 働き／個別から一般を導く推論 |
| 押さえる／抑える | 手で動かないようにする・要点をつかむ／勢いを食い止める（コストを抑える）|

### GOI-03 ら抜き・さ入れ・れ足す言葉【誤り】

| 種類 | 誤 | 正 |
|---|---|---|
| ら抜き | 見れる、来れる、食べれる、起きれる | 見られる、来られる、食べられる、起きられる |
| さ入れ | 読まさせていただく、休まさせる | 読ませていただく、休ませる |
| れ足す | 書けれる、行けれる | 書ける、行ける |

判定方法：一段動詞・カ変動詞の可能形は「られる」。五段動詞の使役は「〜せる」（「読む」→「読ませる」）。

### GOI-06 前後を指す語【任意】

縦書き・改ページを考慮する書籍では「上記・下記・上述・以下」を「前述・次の・前項」などに置き換える。Web 記事など横書きでスクロールする媒体では「上記・下記」も可。文書の媒体に合わせる。

### GOI-07 過剰な敬語・婉曲表現【推奨】

- 「させていただく」は、相手の許可を得て行う場合に限る。単なる行為の報告なら「します」でよい（「説明させていただきます」→「説明します」）。
- 二重敬語（「おっしゃられる」「お伺いさせていただく」）は【誤り】。
- 「〜と思われます」「〜かもしれません」「〜と考えられます」が続く文章は、根拠があるなら言い切る形を提案する（textlint：`ja-no-weak-phrase`）。
- 役職に敬称を重ねない：「部長様」「社長殿」→「部長」「社長」。「各位殿」→「各位」。

### GOI-08 「〜的」「〜化」「〜性」の多用【任意】

一文に「〜的」「〜化」が複数ある場合や、具体的な語に置き換えられる場合に指摘する（「効率的な最適化を実現的に行う」→「効率よく最適化する」）。

### GOI-09 冗長な表現【推奨】

| 冗長 | 簡潔 |
|---|---|
| 〜することができる | 〜できる |
| 〜を行う（設定を行う）| 〜する（設定する）|
| 〜を実施する（テストを実施する）| 〜する【任意】|
| 〜していきます | 〜します【任意：継続・進行の意味があれば可】|
| 〜があるものである | 〜がある |
| 〜ということになる | 〜となる、〜だ |
| 〜であるということ | 〜であること |
| 〜という形で | 〜として |
| 〜というふうに | 〜のように |
| 〜必要性がある | 〜必要がある |
| 〜することが可能だ | 〜できる |
| 〜のほうが（比較の対象がない）| 削る |
| 〜させていただきます | 〜いたします、〜します |

「〜することができる」は、主体の能力・制度上の可否を強調したい場合（「管理者だけが削除することができる」）は残してよい。

### GOI-11 固有名詞・技術用語の表記【誤り】

固有名詞は公式の表記に合わせる。大文字・小文字、スペース、ハイフン、拗音・促音の大小も区別する。

| 誤 | 正 |
|---|---|
| Javascript、javascript | JavaScript |
| Typescript | TypeScript |
| Github、github | GitHub |
| Gitlab | GitLab |
| Webpack | webpack |
| NodeJS、node.js | Node.js |
| NPM | npm |
| MacOS、Mac OS | macOS |
| IPhone、Iphone | iPhone |
| WiFi、Wifi | Wi-Fi |
| Postgresql、Postgres（正式名称として）| PostgreSQL |
| Mysql | MySQL |
| VSCode、VS code | Visual Studio Code（略称は VS Code）|
| Youtube | YouTube |
| Php | PHP |
| ビッグカメラ | ビックカメラ |
| 東京ビックサイト | 東京ビッグサイト |
| キャノン | キヤノン |
| 富士フィルム | 富士フイルム |
| キューピー（企業名）| キユーピー |

コード中の識別子・パッケージ名（`node`、`mysql` など）は対象外（`../checklist.md` の「対象外」）。文章中で製品名として言及している箇所だけを直す。
