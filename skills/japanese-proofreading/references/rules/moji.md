# 文字・記号・体裁（MOJI）

重要度・対象外・表記方針の既定値は `../checklist.md` を参照。

JTF日本語標準スタイルガイドに基づく。媒体ごとの方針で変えてよいものは【任意】とする。

### MOJI-01 句読点【誤り】

- 和文の句読点は全角の「、」「。」を使う。半角の「,」「.」、全角の「，」「．」は使わない。
- 欧文・数値・固有名詞の中のピリオドとカンマ（「Node.js」「1,000」）はそのまま。
- 「，」「．」を句読点とする方針（理工系の論文など）の文書では、その方針で統一されているかを見る【任意】。

### MOJI-02 英数字・カナの全角／半角【誤り】

- 英字・算用数字は半角（「Ａ」「１月」→「A」「1月」）。
- 半角カタカナは使わない（「ｻｰﾊﾞｰ」→「サーバー」）。

### MOJI-03 算用数字と漢数字の使い分け【推奨】

- 数量・順序・日付・番号は算用数字：1月1日、3個、第2章、2倍
- 熟語・成句・概数は漢数字：一般、一部、一時的、一石二鳥、第三者、数十人、十数年
- 「1つ／一つ」「1人／一人」は【任意】。文書内で統一する。

### MOJI-04 助数詞の「か」【任意】

「1ヶ月」「3ヵ所」「5カ国」の「ヶ／ヵ／カ」は、ひらがなの「か」に統一する（1か月、3か所、5か国）。報道で使う「カ」に統一する方針もあるので、文書内で揃っていればよい。漢数字に続く場合は「箇」と書く流儀もある（三箇所、数箇月。公用文）。算用数字に続く場合と書き分けているなら揺れとしない。

### MOJI-05 スペース【任意】

- 全角文字どうしの間にスペースを入れない（「山 川」→「山川」）。これは【誤り】。
- 全角文字と半角英数字の間にスペースを入れるかどうかは方針次第（JTF は入れない。技術書では入れる文書も多い）。文書内で統一されているかを見る。
- かっこの内側・外側にスペースを入れない（「重曹 （炭酸水素ナトリウム） を」→「重曹（炭酸水素ナトリウム）を」）。
- 文末の「？」「！」の後に文が続く場合は全角スペースを入れる（JTF）。文中の「？」の後には入れない。

### MOJI-06 かっこ・記号【推奨】

- 和文中のかっこは全角「（）」「［］」を使う。半角「()」「[]」はコードや欧文の中だけ。
- 和文中に半角ハイフン「-」やダッシュ「―」を区切りとして使わない。範囲は「〜」（東京〜横浜）、補足はかっこや読点で書く。
- 「？」「！」は論述文では多用しない。技術文書では使わない方針も多い【任意】。
- 対になる記号（「」、（）、『』）が閉じているかを確認する。これは【誤り】。

### MOJI-07 不可視・紛らわしい文字【誤り】

コピー＆ペーストで紛れ込みやすく、見た目ではわからないため、検出したら必ず指摘する。

- 制御文字、ゼロ幅スペース（U+200B など）
- 結合文字の濁点・半濁点（NFD）：「エンシ゛ン」「ハ゜ス」のように、文字と濁点が分かれているもの。PDF や macOS のファイル名からのコピーで起きやすい。
- 康煕部首（U+2F00〜）：「⽤」「⼈」など、通常の漢字とほぼ同じ見た目の別文字。検索や読み上げで不具合が起きる。

### MOJI-08 漢字の連続【推奨】

漢字が7字以上続く語句は読みにくい。助詞を補うか、言い換える（「情報処理技術者試験合格者数」→「情報処理技術者試験の合格者数」）。

### MOJI-09 単位・数値の書式【推奨】

- **接頭辞の大文字・小文字**：SI の接頭辞は k（キロ）が小文字、M（メガ）、G（ギガ）が大文字（km、kg、kHz、MHz）。情報量は、1000倍の kB・MB・GB と、1024倍の KiB・MiB・GiB を区別する。「KB」は慣用として広く使われるので、文書内で統一されていれば可【任意】。ビットは b、バイトは B（Mbps と MB/s は8倍違う）。この取り違えは【誤り】。
- **桁区切り**：4桁以上の数に「,」を入れるかどうかを揃える（1,000／1000）。西暦、バージョン、ポート番号、コードの値には入れない。
- **大きな数**：本文で概数を述べるときは「万・億・兆」を使う（5,000,000,000円 → 50億円）。正確な値を示す表やコードは対象外。
- **範囲**：「10〜20%」のように、単位は後ろの数だけに付ける。単位が異なる場合や誤読のおそれがある場合は両方に付ける（500MB〜2GB）。
- **数値と単位の間のスペース**は方針次第（TOITSU-08）。
- **概数**：「約」「ほど」「程度」を重ねない（GOI-04）。

### MOJI-10 文末のコロン【推奨】

和文の文を、コロンで終えない。コードブロックや箇条書きの直前でも、文は句点で終える。

```
△ 次のコマンドを実行します：
○ 次のコマンドを実行します。
```

- 項目名と説明を区切るコロン（「注意：」「例：」「対象：全ユーザー」）は対象外。
- 半角の「:」が和文に付いている場合は、MOJI-01・MOJI-06 と同じく全角にするか、句点に直す。
- 英文の書き方や、生成AI の出力をそのまま使った文章に多い。

### MOJI-11 環境依存文字【推奨】

環境によって表示が変わる、検索や読み上げで扱いにくい文字は、通常の文字で書く。`consistency.py` が件数を集計する。

| 種類 | 例 | 書き換え |
|---|---|---|
| 丸囲み数字 | ①②③ | (1)(2)(3)、1. 2. 3.、番号付きリスト |
| ローマ数字 | Ⅰ Ⅱ Ⅲ、ⅰ ⅱ | I II III（半角英字）、1 2 3 |
| 組文字 | ㈱ ㈲ ㍿ ㎏ ㎝ ㍉ | （株）、（有）、株式会社、kg、cm、ミリ |
| 半角カタカナ | ｻｰﾊﾞｰ | サーバー（MOJI-02）|

画面の表示や原文をそのまま引用している場合、図中の番号と対応させるために丸囲み数字を使っている場合は対象外。
